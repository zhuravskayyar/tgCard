# Artifact sprites

Export 5 base sprites. Artifacts have no element and no rarity-specific file.

```text
weapon.webp
shield.webp
relic.webp
amulet.webp
voodoo.webp
```

Recommended source: transparent background, centered object, square canvas, no rarity frame and no baked rarity glow. Legendary/mythic emphasis is supplied by CSS.
