# CSS rarity layer

No rarity PNG/WebP files are required. Use the classes below on the equipment art container:

```text
rarity-common
rarity-uncommon
rarity-rare
rarity-epic
rarity-legendary
rarity-mythic
```

The current UI uses color, border glow and a lightweight pulse for legendary/mythic. Keep the layer reusable for all 21 base sprites.
