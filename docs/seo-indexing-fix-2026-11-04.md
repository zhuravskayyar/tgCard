- Production: `https://app.cardastika.org/`, Vercel `cardastika`, репозиторій `zhuravskayyar/tgCard`, гілка `codex/cardastika-improvements`, commit `a4ff60766f6cd4cda7bacbfb9504fe93377b6191`.
- `app.cardastika.org/`, `robots.txt`, `sitemap.xml` і `about.html` відповідали HTTP 200 до змін. Головна вже мала canonical, title, description і дозвіл індексації; просто додати їх ще раз недостатньо.
- `cardastika.org` повертав 503. Vercel підтвердив `misconfigured: true`, порожні `aValues` / `cnames` і DNS у Cloudflare. Редирект `cardastika.org` → `app.cardastika.org` з кодом 308 уже налаштований у Vercel, але DNS не веде до нього.
- Опис гри був лише всередині початкового `#root`. `createRoot().render()` замінював його на екран входу без цього опису; мовний провайдер також перезаписував докладний title загальною назвою Світового Дерева.
- Вигаданий URL `/page-that-does-not-exist-seo-check` повертав ту саму головну з HTTP 200 через загальний SPA rewrite.
- Поточний статус URL у Google Search Console в цій сесії не перевірено. Ці дефекти підтверджені; їхній точний внесок у рішення Google про індексацію поки не визначений.

## Локальні виправлення

- Опис гри є і в початковому HTML, і на чинному екрані входу після запуску React. Нову рекламну сторінку не створено; короткий вхід у Telegram збережений.
- Початкові HTML, title, description і мова узгоджені з англійською мовою застосунку за замовчуванням. Опис перекладається українською, англійською, німецькою та російською; неточний hreflang прибраний.
- `/about.html` і `/index.html` отримали постійні редиректи на `/`; sitemap містить лише канонічну головну.
- Загальний rewrite замінений на реальні маршрути гри. Невідомі адреси потрапляють у стандартну обробку 404 Vercel.
- Внутрішні екрани мають `X-Robots-Tag: noindex, follow`; головна й ресурси залишаються доступними для індексації та рендерингу. API rewrite збережений.
- Опис на екрані входу можна прокрутити на мобільному екрані; використано наявне оформлення пергаменту.

## Перевірено локально

- TypeScript і production build клієнта; збірки потрібних workspace `shared` та `game-core`.
- Рендер React: опис доступний без входу, кнопка початку гри збережена, Telegram має короткий екран.
- Збіг початкового опису з англійським перекладом React; переклади всіх абзаців; JSON-LD, sitemap і метадані.
- Офіційний компілятор маршрутів Vercel: 29 маршрутів гри й адміністратора, незмінний маршрут API, редиректи, noindex лише на внутрішніх сторінках і відсутність SPA fallback для невідомих адрес.
- `git diff --check`. Нових runtime-залежностей немає.
- Повний набір тестів сервера й бойової логіки не запускався: зміни ізольовані в публічному описі, метаданих і маршрутизації; цільових перевірок достатньо.

Full test suite not run — change is isolated and low-risk; targeted verification was sufficient.

## Після дозволу на публікацію

Правило `AGENTS.md` вимагає окремого підтвердження перед commit/push/deploy. Після нього: перевірити актуальний head гілки, опублікувати фікси й перевірити production головну, API і посилання Mini App; невідомий URL має віддавати 404, старі публічні URL — постійний редирект, а головна — 200 без noindex. Після виправлення Cloudflare перевірити DNS, HTTPS і редирект основного домену. У Search Console перевірити URL і відрендерений HTML, sitemap і подати запит індексації. Поява в Google не є миттєвою та не гарантується технічною перевіркою.
