# Косметика та інвентар

## Нікові скіни

`nickname_skin_pack_01` — одна пропозиція магазину за 250 золота. Вона містить три незалежні міфічні стилі в дусі середньовічного рукопису (2026-11-12): «Кіновар» (`blood_moon`, червоне чорнило з позолоченим ініціалом), «Сусальне золото» (`starforged`, позолота з повільним відблиском) і «Рунне срібло» (`broken_signal`, гравійоване срібло з рунним сяйвом). Ідентифікатори лишилися старими, щоб куплені стилі не зникли. Кожна покупка приймає конкретний `choiceId`, тому сервер списує золото лише після підтвердження вибору й не дозволяє придбати вже відкритий стиль.

Власність зберігається в `player_cosmetics` (`cosmetic_type = 'nickname_skin'`). Активний стиль зберігається окремо в `players.equipped_nickname_skin`; реальний Telegram username не змінюється.

## API

- `GET /api/shop/nickname-skins` — набір, баланс золота, відкриті стилі та прогрес `0/3`.
- `POST /api/shop/nickname-skins/purchase` з `{ "choiceId": "blood_moon" }` — атомарно відкриває стиль, списує 250 золота і автоматично екіпірує вибраний стиль.
- `GET /api/player/inventory` — інвентар із секціями `cosmetics` та `items`.
- `POST /api/player/inventory/nickname-skin/equip` з `{ "skinId": "starforged" }` або `{ "skinId": null }` — перемикає вже придбаний стиль або повертає стандартне оформлення.

Надалі нові серії можуть додаватися як окремі набори з власним ID та списком choices, не змішуючи їх із картковими пропозиціями.
