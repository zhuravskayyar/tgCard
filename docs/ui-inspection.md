# Інспекція інтерфейсу після коментаря 28.10.2026

Початкова проблема відтворена у відкритому локальному браузері користувача:
375×668, світла тема, справжній гравець 1 рівня з локальної PostgreSQL.
Попередня перевірка ширини сторінки та досвідченого гравця не покривала
накладання декорацій і підписів новачка на невисокому екрані.

## Знайдене й виправлене

| Дефект | Причина | Правка |
| --- | --- | --- |
| Малюнки меню перетинають назви й «Пізніше» | Абсолютне позиціонування та 38% ширини без резервування місця | Окремі колонки для іконки, назви, малюнка, стану й стрілки; назва може переноситися |
| Майже невидиме «СКОРО» | Темне чорнило на темній плашці | Світлий текст; контраст перевіряється тестом |
| Дрібні зони натискання та стискання на короткому екрані | Рядки 30–36 px, кнопка налаштувань 28 px, примусове вміщення всього меню | Рядки та кнопки по 44 px; коротка сторінка прокручується між HUD і навігацією |
| Число сили колоди потрапляє на край заголовка | Права дія використовувала відступ 22 px при декоративному торці 60 px | Збільшений правий відступ заголовків із діями |
| Назви секцій налаштувань лежать на рамці | Рамка 22 px не резервувала місця у вмісті | Внутрішні відступи; вкладені settings-card без дубльованої рамки |
| Google-віджет розсуває рядок і виштовхує назву | Фіксована ширина 320 px та масштабування без зміни розміру колонки | Назва і віджет розташовані вертикально; ширина віджета визначається контейнером і оновлюється ResizeObserver |
| Telegram показує `Bot domain invalid` на localhost | Локальна адреса не є дозволеною адресою Telegram-віджета | У локальному браузері показана підказка відкрити Mini App; налаштування бота не змінені |
| Порожні слоти спорядження виглядають як порожні плитки | Уже наявна іконка типу слота рендерилася лише за наявності предмета | Для порожнього стану показано існуючий приглушений символ; слот лишається порожнім у даних та aria-label |

## Перевірки

- `home-layout.spec.ts`: реальний новий гравець через локальний `/api/auth/guest`;
  світла й темна теми; 320×568, 375×668, 430×932 та 668×375.
- Перевіряються перетини малюнків із текстом, межі текстових рядків, висота
  кнопок, контраст «СКОРО» та доступність останнього пункту над нижньою навігацією.
- Окремий тест перевіряє зміну ширини Google-віджета й межі секцій при
  зміні ширини 430 → 320 → 375. Зовнішній SDK замінено тестовим адаптером;
  дані гравця та сервер авторизації справжні, вхід у Google не виконується.
- `theme-surfaces.spec.ts`: 17 маршрутів в обох темах на 320×568, 375×668,
  430×932; додатково карта, повернення назад і перемикач теми.
- Порожні слоти профілю перевіряються окремо: є символ типу, немає позначки
  екіпірованого предмета, підпис доступності містить «Порожній слот».
- Візуально переглянуті головна, колода, профіль, магазин, налаштування та
  гільдія у локальному браузері. Завантаження та початкова анімація відрізняються
  від кінцевого стану екрана; вони не вважаються підтвердженням фінальної верстки.

Перед оновленням PR повний набір повторено з локальною БД: game-core 71/71,
server 109/140. Список 31 падіння збігається з попереднім запуском.
Ця інспекція не змінює сервер, схему БД, каталог, економіку чи правила гри.

Активна публічна Mini App досі веде в інше середовище, а не до localhost.
Для перевірки цих правок саме в Telegram потрібне окреме локальне підключення.
Випуск у production не входив до цієї інспекції.

Підсумок запусків: 7 тестів головної/налаштувань/тем пройшли; додатковий тест
порожніх слотів також пройшов. Клієнтська збірка й TypeScript успішні,
`git diff --check` без помилок.

Google SDK у локальному браузері додатково повідомляє `The given origin is not
allowed for the given client ID`. Геометрія його кнопки перевірена, зовнішній
вхід не виконувався; дозволені адреси OAuth у цій задачі не змінювалися.
