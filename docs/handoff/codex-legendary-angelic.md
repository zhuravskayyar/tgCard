# ТЗ для Codex: легендарні карти — «ангельський дамаск»

Дата: 2026-11-12. Передає: Claude (закінчуються ліміти). Відповідати користувачу **українською**.

## 1. Як ми працюємо (обовʼязково)

1. **Local-first** (див. `AGENTS.md`): усі зміни лише локально. **Ніколи не пушити й не деплоїти** без явної команди користувача («пуш», «добре», «можна в прод»). Перед пушем — `git fetch` і перевірити, чи не змінилось `main`.
2. Почни з `docs/map/index.md`, код шукай через `graphify query "<питання>" --budget 800`; після змін — `graphify update .`.
3. Перевірки пропорційні: для шейдера достатньо `npx tsc -p client --noEmit` + візуальна перевірка. Повний набір тестів не запускати.
4. **Файли з кирилицею не редагувати через PowerShell Get-Content/Set-Content** (ламає кодування) — тільки редактор, Node або Python з `encoding="utf-8"`.
5. Цикл показу: зробив варіант → показав користувачу кадри (компʼютер) і телефон з FPS → чекаєш на фідбек. Не ганяй однакові команди по колу; користувач перериває, коли бачить зайві дії.
6. Стиль гри: світла «пергаментна книга», гравюра таро (чорна туш + крем). Мобільна колонка 430px. Усі поверхні — намальовані спрайти, CSS лише для розкладки.
7. Не трогати міграції 064/065. Секрети/env не читати.

## 3. Завдання

Переробити гілку легендарної карти (kind 9, блок `// Legendary, angelic` у `cardMaterialShader.ts`) так, щоб це читалось як **ангельське золото з дамаском**:

1. **Повернути дамаск.** Оригінальний візерунок gold-damascus є в останньому коміті: `git show HEAD:client/src/cards/cardMaterialShader.ts` (гілка `kind > 8.5`). Узяти звідти шари дамаської сталі (хвилясті смуги/ковані шари) як основу тіла карти — тепле насичене золото, не бліде.
2. **Ангельськість — світлом, а не жовтим кольором**: м’яке біле сяйво згори, чіткий тонкий німб/кільце за фігурою, біла аура по силуету, повільні промені; можливо — крила світла або пір’я по краях. Ефект має бути «святим/небесним» контрастом до пекельної міфічної: та темна й червона, ця — світла, біло-золота, з глибиною.
3. Фігура має лишатися читабельною (темні лінії гравюри на золоті).
4. Плашка сили: зараз темна бронза з біло-золотими цифрами — читабельна, можна залишити або доробити в тому ж стилі, що й рамка.
5. Анімація плавна, без мерехтіння; на малих картках (колода) кадрів мало — уникати швидких змін.

**Критерії приймання:** користувач каже, що це схоже на ангельський ефект і дамаск видно; на телефоні колода ≥ 58 FPS (зараз 59,5 avg), детальна картка 60 FPS; `tsc` чистий; міфічна не змінилась.

## 4. Як показувати

**Компʼютер:** `npm run dev` у клієнті (`http://localhost:5173`), сторінка детальної картки з `?allLegendary=1`. Кадри з canvas: `document.querySelector('.card-detail-card canvas.card-material-shader').toDataURL()` кілька разів з інтервалом ~1,5 с, показати сіткою.

**Телефон (Android, adb):**
- Сервер для телефона: `npm run phone` (білд у `.runtime/phone-dist`, LAN `http://192.168.0.126:4173`). Після зміни шейдера дочекатися перезбірки (повідомлення «Клієнт перезібрано»).
- `adb` = `.runtime/platform-tools/adb.exe`; `adb reverse tcp:4173 tcp:4173`, `adb forward tcp:9333 localabstract:chrome_devtools_remote`.
- Відкрити: `adb shell am start -a android.intent.action.VIEW -d "'http://localhost:4173/deck?allLegendary=1&allMythic=0&fps=1'" com.android.chrome` (у Git Bash — `MSYS_NO_PATHCONV=1`).
- FPS читати з `window.__cardastikaPerf` через CDP на `127.0.0.1:9333` (сторінки з `/json`, `Runtime.evaluate`), 12 секунд, середнє й мінімум.
- На телефоні **інший гравець**, ніж на компʼютері: id карток з компʼютера там не відкриваються — заходь у детальну картку з колоди телефона.
- Скріншот: `adb exec-out screencap -p > shot.png`.
