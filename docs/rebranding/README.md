# Нові карти

У `new-card-catalog.json` збережені метадані дев’яти стартових карт. Коли з’являться малюнки, поклади окремий файл гравіювання кожної карти сюди:

`client/public/card-art/new-cards/`

Для стартового набору використовуй назви `starter_v2_01`…`starter_v2_09`; номер відповідає порядку карт у `new-card-catalog.json`. Наприклад, для Рогача з ігровим ID `starter_v5_02` файл називається `starter_v2_02.png`. Підтримуються `.webp`, `.png`, `.jpg` і `.jpeg`; ім’я без розширення вже прив’язане в мапі арту, тож файл з’явиться після перезавантаження локальної гри.

Борсук уже підключений до доданого файлу `starter_v2_01.png`; його поточна прив’язка вказана в `new-card-catalog.json` та `client/public/card-art/card-art-map.txt`.

Спрайти накладаються за Material Shader V7: зберігаються прозорість і внутрішні деталі, палітра підлаштовується під матеріал рідкості, а край отримує м’який рельєф. Використовуй окремий спрайт із прозорим фоном, без рамки, числа сили й значка стихії.

Поки збираємо новий набір, у грі активні тільки ці дев’ять стартових карт. Старі колекції, лімітовані карти та карткові пропозиції магазину збережені в локальній БД як архів, але не показуються й не видаються.
