# Campaign art prompts

Це готові промпти на випадок, якщо для кампанії знадобляться окремі портрети
або іконки. Зараз усі портрети відправників і босів беруть наявний арт каталогу;
бракує саме десяти іконок локацій. Промпти портретів — запасний план для
майбутнього, а не вимога замінити чинні картки.

Портрети зроблені за правилами `docs/card-art-workflow.md`: квадратний PNG з
альфою, похмура таро-ксилографія, чорна туш і плоска кремова заливка, без рамки
чи тексту. Для гуманоїдів зберігай анатомію рук: рівно чотири пальці на кожній
руці — один великий і три інші; усі персонажі дорослі, без оголення.

Іконки карти — окремі UI-спрайти у стилі пергаментної книги з
`docs/ui-style-review.md`: папір `#EAD5AA` / `#F0DFBC`, сепійне чорнило `#2D1B0E`,
темна бронза `#74491F`, світла бронза `#B1814E`; фронтальний ортографічний
ракурс, прозора альфа поза силуетом, без тла, тіні, сяйва, рамки з текстом,
літер, чисел, логотипів чи водяного знака.
