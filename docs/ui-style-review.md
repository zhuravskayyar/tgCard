# Перевірка книжкового стилю і тем — 28 жовтня 2026

Вихідний матеріал: «Cardastika — огляд стилю PR #3 і набір спрайтів».
Документ поєднує підтверджувані дефекти CSS і пропозицію майбутнього повного
набору графіки. Реалізацію звірено з поточним кодом і локальною грою.

## Що підтвердилося

- `book-theme.css` задавав світлі токени для будь-якої теми. Через це перемикач
  змінював атрибут документа, але оформлення залишалося пергаментним.
- Пошук дуелі мав окрему зовнішню рамку, рамку спрайта, CSS-обведення,
  додаткові кільця тіні та декоративну лінію. Суцільні фони під прозорими
  кнопками утворювали прямокутники навколо їхніх країв.
- Квадратна панель використовувалася для довгої другорядної кнопки.
- Одна панельна рамка застосовувалася і до секцій, і до їхніх дочірніх рядків.
- `MenuRow` використовував різні матеріали й додаткову намальовану CSS смугу.
- Заголовки повторювали розмітку кнопки «назад», підзаголовка та назви.
- Числа HUD мали темну металеву заливку незалежно від теми.

## Прийняті рішення

1. Окремий `theme-sprites.css` вибирає матеріали через CSS-змінні. Світла тема
   використовує пергамент; темна — темне дерево й бронзу.
2. Книжкові перевизначення обмежено `data-game-theme="light"`. Спільна геометрія
   HUD, меню, пошуку дуелі та екрана карти збережена між темами.
3. `ScreenHeading` відповідає за заголовок, назад, підзаголовок і праву дію.
   Обробники навігації, підказки навчання, підписи доступності та повернення
   фокуса збережені. Вкладені екрани гільдії не отримують дубльованої шапки.
4. `MenuRow` і адаптери з `MenuTextureSlices` використовують один спрайт.
   Компактне розміщення екрана карти збережене без іншого матеріалу рамки.
5. Панелі верхнього рівня отримують рамку з кутами 64 px і шириною 22 px.
   Вкладені рядки використовують розділювачі. Для трьох частин кнопок і меню
   кінці залишаються фіксованими, розтягується середина.
6. Медальйон сили використовує наявний `game/nav-medallion-v1.webp`.
   Підкладку із запеченим фоном на екрані карти замінено спільною панеллю.
7. Фарбовані іконки навігації екрана карти замінено на наявні `AppIcon`.

## Використаний набір промптів

Спільна книжкова специфікація: old illustrated grimoire; aged handmade parchment
`#EAD5AA` / `#F0DFBC`, sepia ink `#2D1B0E`, dark forged bronze `#74491F`, aged
bronze highlight `#B1814E`, iron `#3A2A1A`; small rivets, engraved leaf filigree,
soft top-left lighting, front-facing orthographic view, real transparent alpha,
no text, numbers, logos, glow, backdrop or drop shadow.

- Panel: square, plain uniformly textured center, frame about 1/8 of width,
  ornamental corners with one rivet each, stretchable uniform straight sides.
- Primary: 6:1 horizontal button, narrow matching bronze frame, uniform
  oxblood leather `#5A1A10`, small end caps, no center ornament.
- Menu row: 7.5:1 band, recessed circular icon socket at left, pointed right
  tip, thin border, plain empty stretchable middle, no center ornament.
- Heading: symmetric 6.5:1 plaque, pointed ornamental ends with rivets,
  plain uniform band, no icon socket or center ornament.
- Secondary: same silhouette as primary; parchment center, quieter frame.

Панель була матеріальним референсом для трьох основних смуг. Головна кнопка
стала референсом другорядної. Для кожної темної версії відповідний книжковий
спрайт був референсом форми: preserve silhouette, proportions and ornament
positions; replace parchment with matte dark charred oak / stone `#1B1712`,
near-black `#14110D`, elevated wood `#282016`, worn bronze `#B1814E`, restrained
accent `#DFBA74`; preserve oxblood only for primary; no pale parchment.

## Перевірка Telegram

Активна адреса меню бота — `https://app.cardastika.org`. Вона віддає Cardastika,
`/api/health` відповідає 200, невалідна Telegram-авторизація — 401.
Але публічний `/api/dev/accounts` відповідає 404 при локальному 200,
HTML використовує іншу збірку, а Cloudflare Tunnel не працює ані у Windows,
ані у WSL. Отже, ця адреса зараз веде в інше середовище, не до поточного
локального сервера. Зміни меню бота чи публічного середовища не виконувалися.
Керування вікном Telegram також заблоковане перевіркою Computer Use,
яка не змогла надійно визначити URL вікна браузера.

## Результати локальної перевірки

- PostgreSQL: авторизовані запити читають локального гравця з БД;
  HUD показує його ім'я, рівень, срібло і золото без помилок.
- Повна `npm run build`: успішно, включно з TypeScript і клієнтською збіркою.
- Браузер: обидві теми, 17 основних маршрутів на 320, 360 і 430 px,
  додатково деталі карти; горизонтального переповнення та помилок JS немає.
- Перемикач теми відразу змінює спрайти; вибір зберігається після перезавантаження.
- Кнопки «назад» повертають з карти в колоду і з колоди на головну.
  Темні підписи захисту та валют перевірені окремо після візуального перегляду.
- У всіх перевірених екранах є один HUD і три незмінні кнопки нижньої навігації.
- 10 нових WebP: прозорість перевірена, посилання існують, кожен менше 150 КБ.
- `git diff --check`: без помилок.
- Повна `npm test` з локальною БД: game-core 71/71, server 109/140.
  31 серверна перевірка падає в областях каталогу, початкових карт, нагород,
  прогресії та магазину. Приклади: `Missing canonical boss card starter_v5_01`,
  `No free battle pass card reward is configured`, звернення до відсутньої
  пропозиції магазину в `shopChancePolicy.test.ts`. Сервер, shared і game-core
  у цій правці не змінювалися; повний набір не можна позначати успішним.

Результат перевірено локально. Для підтвердження саме в Telegram потрібне
підключення окремого середовища розробки до локального сервера.
