# Магазин: «Детальніше»

Перевірено в авторизованому браузері 2026-11-03, лише читання:

- `/shop/cards/`: короткі пропозиції з шансом кращої рідкості, покупкою та посиланням «Подробнее».
- `/shop/cards/info/4001/`: окрема сторінка з поточними шансами, покупкою й сіткою доступних карт, згрупованих за рідкістю від вищої до нижчої.
- `/shop/cards/cardinfo/elvish_princess_1/`: арт, назва, опис, факт попереднього отримання, колекції та їхні бонуси.

У Cardastika цей шлях живе всередині `ShopScreen`, зберігаючи загальні `TopHud` і `BottomNav`. Назад з опису повертає до тієї ж пропозиції; назад з пропозиції — до списку карт. Оформлення й компоненти залишаються власними.

Список і рідкість карт приходять із каталогу магазину. Опис, отримання, кількість копій і колекції читаються через авторизований `GET /api/shop/cards/info/:cardId`, який повторно використовує `CollectionRepository`. У React немає копії каталогу чи вигаданого стану гравця.

Перевірка власного сайту, публічного API та Telegram Mini App відкладена до дозволеного пушу відповідно до `AGENTS.md`.
