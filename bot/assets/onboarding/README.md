# Cardastika onboarding assets

Place real screenshots of the Mini App in this folder using these exact names:

- `01-main.jpg` — main menu;
- `02-cards.jpg` — collection or deck;
- `03-battle.jpg` — duel or battle;
- `04-guild.jpg` — guild;
- `05-profile.jpg` — profile, equipment, or progression.

The bot skips files that are not present. It never generates or sends fake
screenshots; until the assets are added, `/start` uses a short text fallback and
still shows the Mini App launch button.
